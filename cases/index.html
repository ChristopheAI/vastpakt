Een voorraadapp die na een jaar nog elke dag draait

Poedervoorraad bijhouden bij een poedercoating-bedrijf: stock in, verbruik eruit, correcties met een spoor. Dagelijks gebruikt op de werkvloer, met 135 voorraadregels en 1.822 kg poeder in beheer.

  • Auditbare mutatielog: elke correctie traceerbaar
  • Aparte rollen voor admin en operator
  • Databasemigraties draaien automatisch mee in de deploy
  • Nachtelijke versleutelde backups

— de zaakvoerder, na ruim een jaar dagelijks gebruik

Een uur per dossier terug voor een plaatsbeschrijver

Een plaatsbeschrijver spreekt zijn plaatsbezoek in. De tool haalt zijn vaststellingen uit het transcript en zet ze op de juiste plaats in zijn eigen Word-sjabloon. Elk rapport wordt nagekeken voor het vertrekt. De echte app draait hier in demo-modus op een fictief voorbeelddossier.

  • ±1 uur bespaard per dossier
  • De schrijfstijl van de expert zit gecodeerd in het systeem
  • Gevalideerde extractie, rechtstreeks in de docx-XML
  • Controle op volledigheid en ontbrekende onderdelen vóór download

Eigen werk & open source

Op eigen initiatief gebouwd. De code en de demo's staan open; er zit geen klantdata in.

Bloedwaarden-dashboard

Persoonlijke Laravel-app: labo-PDF uploaden, waarden reviewen, daarna historiek en vergelijking. Alleen bevestigde waarden gaan door, dat is een harde grens. Diagnose en medisch advies laat ik aan de arts. Echte labodata blijft privé; de code is open.

  • PDF-first intake met confidence; onzekere rijen naar review
  • Confirmed-only: dashboard en export zonder stille fouten uit extractie
  • Domeinmodel in PHP (intake, biomarkers, consult-prep, privacy-export)
  • Tests, CI, ADRs — gebouwd met agentic coding + data-discipline op de public repo

Prospectie-engine: koopsignalen uit registerdata

Een bedrijvendatabase die koopsignalen oppikt en scoort — niet alleen wat bedrijven zeggen, ook wat ze doen in registerdata. De demo draait read-only op voorbeelddata, login staat op de pagina.

  • Warmth-score 0–100: welke lead bel je éérst?
  • Registerdata als signaal: KBO-mutaties en jaarcijfers naast wat bedrijven zelf posten
  • Dossier per bedrijf met uitsplitsing van de score
  • Kaartweergave en CSV-export

Hoe deze gebouwd zijn

Met agentic coding agents (Claude Code, Codex): zij schrijven de code, ik geef richting en review tot het klaar is voor productie. Dat is iets anders dan AI-autocomplete in VS Code of alleen sneller typen in een editor.

Bekijk mijn GitHub
  • Agents schrijven de code; ik zeg wat er moet en wat niet mag breken
  • Review tot het door CI, tests en mijn check is — “done” is geen vibes
  • Meerdere agents tegelijk; ik hou de richting
